# Mahika Bommana — Portfolio V2

A light, editorial portfolio inspired by cinematic developer portfolios while keeping the design original, professional, elegant, and aligned with Mahika's AI/ML identity.

## Run locally

```powershell
npm install
npm run dev
```

Open http://localhost:3000

## Design direction

- Light warm-ivory theme
- Strong editorial typography
- Soft terracotta, sage, and powder-blue section accents
- Large full-screen storytelling sections
- Cinematic talking-avatar hero
- Selected projects presented as editorial case-study cards
- Responsive, accessible motion using Framer Motion

## Pages

- Home
- About
- Projects
- ASTRAARM ROS2 case study
- Technology
- Journey
- Contact
